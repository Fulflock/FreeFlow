## Ce que ça fait

- **Pousse-pour-parler** — Maintiens `Ctrl + Espace`, parle, lâche. Le texte est collé là où est ton curseur.
- **100 % privé** — La transcription tourne sur ton processeur (Whisper embarqué). Ton micro ne quitte jamais ta machine.
- **Fonctionne hors-ligne** — Aucune connexion requise.
- **Multi-langue automatique** — Français, anglais, espagnol… avec détection auto.
- **Dictionnaire perso** — Apprends-lui tes noms, marques et jargon.
- **Snippets vocaux** — Un mot-clé → un bloc de texte tout prêt.
- **Tableau de bord** — Mots dictés, temps gagné, séries… en local.
- **Mises à jour automatiques** — Incluses à vie.

## Comment ça marche

1. Maintiens `Ctrl + Espace`
2. Parle
3. Lâche — ta phrase est transcrite instantanément
4. Le texte est collé là où tu cliques

Fonctionne dans **toutes les applications** — navigateur, Word, Slack, Discord, etc.

## Configuration requise

- Windows 10 / 11
- ~500 Mo de RAM
- Pas de GPU nécessaire (tourne sur le CPU)
