Les questions qu'on se pose

C'est vraiment gratuit ? +
Oui, 100% gratuit et sans limite. Pas d'essai, pas d'abonnement caché, pas de version « Pro » payante. FreeFlow est open source sous licence MIT.
Mes paroles sont-elles envoyées quelque part ? +
Non. Toute la transcription se fait sur ton ordinateur grâce au modèle Whisper embarqué. Ton audio ne quitte jamais ta machine — et ça marche même sans connexion internet.
Pourquoi Windows m'avertit à l'installation ? +
Parce que l'app n'est pas encore signée numériquement (un certificat coûte cher pour un projet gratuit). Clique sur Informations complémentaires puis Exécuter quand même. Le code est public sur GitHub, tu peux tout vérifier.
Comment je mets à jour ? +
Automatiquement. FreeFlow vérifie les nouvelles versions au lancement et te propose de les installer en un clic — pas besoin de retélécharger à la main.
Quelle touche pour dicter ? +
Par défaut, Ctrl + Espace : tu maintiens pour parler, tu lâches pour transcrire. Tu peux choisir ta propre combinaison dans les Réglages.
Ça marche sur Mac ? +
Pas encore — FreeFlow est pour Windows 10 et 11 pour le moment. Une version Mac est une possibilité pour plus tard.
